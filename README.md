# Developer-Burnout-Layoff-Risk-Career-Stability-Analytics
Interactive workforce analytics dashboard built using Python, PostgreSQL, SQL, and Power BI to analyze developer burnout, layoff risk, 
mental health indicators, AI replacement fears, and career stability patterns.
## Project Overview
This project analyzes workforce well-being and career stability using Python, PostgreSQL, SQL, and Power BI. The objective is to uncover 
insights into employee burnout, job security, layoff anxiety, AI-related concerns, career growth, and job-switching behavior to support 
data-driven HR and workforce management decisions.

# Developer-Burnout-Layoff-Risk-Career-Stability-Analytics
Interactive workforce analytics dashboard built using Python, PostgreSQL, SQL, and Power BI to analyze developer burnout, layoff risk, mental health indicators, AI replacement fears, and career stability patterns.
## Project Overview
This project analyzes workforce well-being and career stability using Python, PostgreSQL, SQL, and Power BI. The objective is to uncover insights into employee burnout, job security, layoff anxiety, AI-related concerns, career growth, and job-switching behavior to support data-driven HR and workforce management decisions.

The project includes:

- Data cleaning and preprocessing using Python
- Business analysis using SQL queries in PostgreSQL
- Interactive dashboard creation in Power BI
- Burnout and layoff risk analysis
- AI fear and career stability analysis
- Career growth and job-switching insights
- Business recommendations based on analytical findings

## Tools & Technologies

## Dataset Summary
- The dataset used in this project is available publicly on Kaggle: https://www.kaggle.com/datasets/shambhurajejagadale/indian-developer-burnout-and-layoff-anxiety-dataset?resource=download
- Records: 5,000 software professionals
- Features: 50 columns
- Include:
  - Employee demographics
  - Career and company information
  - Salary and financial preparedness
  - Burnout, anxiety, and stress indicators
  - Job security and layoff risk metrics
  - AI replacement fear and upskilling behavior
  - Career growth and job-switching patterns
